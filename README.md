# GREATSTAR AUTO-WIRING & SENSOR PRO 🚗⚡
### ကားတစ်စီးလုံး ဝါယာရိန်း၊ ဆန်ဆာ & ECU ထိန်းချုပ်မှု မာစတာလက်စွဲ (Automotive Electrical & Sensor Master Directory)

Designed and curated for automotive technicians, auto electricians, and workshop masters.

---

## 🌟 အဓိက ပါဝင်သော ကဏ္ဍကြီးများ (Core Modules):

1. **⚡ ၁။ ပါဝါ & ဂရောင်း ဖြန့်ဝေမှု စနစ် (Power & Ground Architecture):**
   - 4-Pin / 5-Pin Relay ပင်နံပါတ်များ (30, 87, 87a, 85, 86)
   - Voltage Drop စစ်ဆေးနည်း (< 0.2V Golden Rule)
   - Chassis Ground နှင့် Sensor Ground (E1/E2) ခွဲခြားခြင်း

2. **🔌 ၂။ ကားကုမ္ပဏီအလိုက် ECU Pinout ဘာသာပြန်ဇယား (Multi-Brand Pinout Matrix):**
   - Toyota / Lexus (BATT, +B, IGSW, MREL, VC, E1, E2, NE, G)
   - Honda, Nissan, Hyundai/Kia, Ford, Mercedes-Benz

3. **🔍 ၃။ ဆန်ဆာ (၃၈) မျိုး လမ်းညွှန် (Master Sensor Directory):**
   - CKP, CMP, MAF, MAP, O2/AFR, TPS, ECT, Knock, Rail Pressure, Rail Limiter, ABS Speed, etc.
   - Operating Voltages, Resistance, Multi-meter test points, Waveform diagrams

4. **⚙️ ၄။ အီလက်ထရောနစ် လေတံခါး / VVT-i / EGR / အဲကွန်း (Assemblies):**
   - ETCS-i Dual TPS (VTA1 + VTA2)
   - VVT-i Oil Control Valve (OCV) PWM Duty Cycle
   - Stepper vs Linear EGR Valve
   - Variable Displacement A/C Compressor Solenoid

5. **🛡️ ၅။ ဖျူးခုံ & အရောင်စံချိန် (Fuse Box & Color Code Standards):**
   - Fuse Ampere Color Standards (5A Tan to 30A Green)
   - Common Fuse Abbreviations (EFI, ECU-B, AM1, AM2, DOME, STOP, IGN)

6. **🎛️ ၆။ အတွင်းခန်း ခလုတ်များနှင့် သင်္ကေတများ (Interior Symbols & Switches):**
   - Steering Wheel Switches, Climate Controls, Drive Modes, Mirror & Door Controls

7. **🚦 ၇။ ဒိုင်ခွက် မီးနီ/မီးဝါ အပြည့်အစုံ (Dashboard Warning Vector Lights):**
   - Red Danger Warnings, Yellow Caution Indicators, Green/Blue Status Indicators

8. **✨ ၈။ စက်မသုံးဘဲ လက်ဖြင့် Reset နည်းများ (Secret Manual Resets):**
   - Engine Oil Chain Reset, Power Window Initialization, T-BELT 150,000 km Reset
   - Honda Oil Life 100%, Back Camera Guideline Calibration, TPMS Relearn, Throttle Idle Relearn

9. **🇯🇵 ၉။ ဒိုင်ခွက် & TV ဂျပန်စာ ဘာသာပြန် (JDM Screen Decoder):**
   - Japanese Kanji / Katakana Matching (設定, メンテナンス, 初期化, オイル交換, はい, 完了)
   - Step-by-Step Screen Click Navigation Paths

10. **💻 ၁၀။ OBD-II အယ်တာကုဒ် DTC မာစတာ (Master DTC Decoder):**
    - P, C, B, U Code Breakdown
    - Circuit High (Open Circuit / 5V Pull-up) vs Circuit Low (Short to Ground / 0V)
    - Range / Performance, Misfire, Network Lost Communication

11. **🛠️ ၁၁။ DIY ဆန်ဆာစမ်းသပ်ခုံ (Sensor Tester Workbench):**
    - L7805 5V Regulator + BC547 Transistor Circuit Diagram
    - Hall Effect & Magnetic Inductive Sensor Bench Testing
